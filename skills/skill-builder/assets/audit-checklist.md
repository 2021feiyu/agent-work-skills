# Skill 质量检查清单（10 项）

创建或修改 Skill 后，逐项检查。全部通过才算合格。

## 检查项

| # | 检查点 | 标准 | 通过 |
|---|--------|------|------|
| 1 | description 是否明确了触发条件和能力边界？ | 含 trigger keywords + do/do NOT 边界 | [ ] |
| 2 | SKILL.md 是否少于 500 行？ | 超过 500 行应拆分 | [ ] |
| 3 | 是否每个 Skill 只解决一个问题？（单一职责） | 不混入无关能力 | [ ] |
| 4 | 是否有代码示例或命令模板（而非纯文字）？ | 至少一个可执行的代码块 | [ ] |
| 5 | 是否有 Gotchas 部分预防常见错误？ | 至少 2 条 AI 容易犯的错 | [ ] |
| 6 | 详细文档是否移到了 references/？ | SKILL.md 不塞大段参考文档 | [ ] |
| 7 | 需要确定性执行的操作是否写成了 scripts/？ | 重复操作用脚本，不靠 AI 即兴 | [ ] |
| 8 | allowed-tools 是否为最小权限？ | 不用通配 Bash 全权限 | [ ] |
| 9 | name 是否全小写 + 连字符？ | 示例: `my-skill` 非 `MySkill` | [ ] |
| 10 | 是否假设了工具已安装？（应写明安装命令） | 依赖项有 pip install / apt-get 说明 | [ ] |
