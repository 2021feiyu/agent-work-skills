> 行号对应当日文件，后续原文件变化后应重新定位。代码审查发现不等于已完成当前版本的视觉验收；截图证据必须绑定成品哈希。

## 2. P1：组织架构 V4

### 证据

- P1:315–319 用 `new Date()` 更新顶部月份；P1:303–304 页脚保留固定 `2026-09`。
- P1:321–329 用 `scale()` 让整张组织图适应宽度。
- 细边、虚线空缺岗位和米白/墨蓝/金色体现了明确的品牌层级。

### 通用化

- 数据截至、成品生成、页面打开三类时间分开；数据期间只来自元数据。
- 移动端验收“可读性”而非只验收无溢出；复杂图形可平移、折叠或换列表，不无限缩小。
- 形状和虚线作为颜色之外的第二编码值得保留。

### 不泛化

竖排组织树、整体缩放和该项目署名/月份不是普通看板规则。

## 3. P2：AI 应用规划 V7

### 证据

- P2:535–539 KPI 写 `11 项`；P2:2653–2663 双环分别写 5/5/1 与 3/6/1/1；P2:2670–2675 中心再写 `11 项工具`。
- 顶部章节条、右侧 dock 和移动面板同时存在；移动面板使用 menu 语义但未形成完整菜单行为。
- reveal 采用 `.js` 门控，避免无 JS 时被 reveal 规则隐藏，这一方向正确。

### 通用化

- 跨视图计数同源，至少断言 `KPI = 图表合计 = 明细行数 = 中心文字`。
- 多入口导航由 registry 生成，但同一断点只保留一个全局导航，避免重复维护与注意力分散。
- 普通章节链接不伪装成 menu；使用原生链接或完整实现相应键盘模型。

### 不泛化

十章结构、双环图和具体主题属于该项目内容策略。

## 4. P3：AGI 应用技能培训 V5

### 证据

- P3:982 的 `data-nav="任务执行与技能沉淀"` 与 P3:986 的 H1“任务工程：指令设计 与 能力沉淀”不同。
- 分片构建、导航生成、深链、滚动记忆与打印展开是可复用工程资产。
- 既有浏览器断言覆盖多档视口，但 reduced-motion、键盘焦点、无 JS 与打印仍需独立证明。

### 通用化

- PageRegistry 不只生成导航，还应形成导航名/H1/元信息的命名契约。
- 深链和滚动位置按页面设计，不能所有切页统一回顶。
- 验收记录中的截图数量由工具生成，不多份文档手工重复。

### 不泛化

课程名称、13 个页面、旧锚点兼容和培训内容保全规则不进入普通看板硬约束。

## 5. P4：国产模型全景选型 V6

### 证据

- P4:1397–1413 将带 `*` 的官方口径与其他数据放入同一 Terminal-Bench 排序序列；同页方法说明又禁止跨口径排名。
- P4:698 先将 950×0.13+50×5.98=422.5 显示为 423，再换算成 ¥3,046；若保留全精度乘 7.2，应为 ¥3,042。
- P4:704 写“从 $130 涨到 $423——多花 3.3 倍”，混淆“涨至约 3.3 倍”和“增加约 2.3 倍”。
- 结论前置、统一 `hbar()`、排序和明确对数轴是值得复用的设计底座。

### 通用化

- 口径类型进入数据结构；不同口径不得进入同一排序序列，星号不能替代分面。
- 计算全精度保留，展示最后统一舍入。
- “是 N 倍 / 增加 N 倍 / 差 N 个百分点”使用独立模板并复算。
- 测量事实、工程解释和编辑推断分层表达，不能把相关关系写成已证明因果。

### 不泛化

纸本色板、模型风险路由、编辑评分和成本对数轴是领域决策。

## 6. P5：人力经营驾驶舱 V39

### 证据

- P5:1377–1384 的全局 `V_BASE` 固定首次动画 900ms；P5:3281 只在切页 replay 前检查 reduced-motion。
- P5:3280 注释称 900+600 约为 1.2s；P5:3288 锁为 1400ms；P5:3303–3305 还增加每点 `idx*28`，实际可能超过锁时长。
- P5:3385 回顶固定 `behavior:"smooth"`，未读取 reduced-motion。
- FilterManager、统一 applyPages、实例复用、mk/vTheme、切页 resize 和打印降级是高质量底座。

### 通用化

- reduced-motion 同时覆盖首次、更新、replay、CSS 和 JS 滚动。
- 动画预算按真实最大 delay+duration 计算；更推荐最新任务优先，避免固定长锁。
- 图表实例与主题统一注入，筛选只更新数据，不重新 init。
- 全交付面哈希必须包含项目外“最新/分发”副本。

### 不泛化

特定玻璃参数、主体配色、权限分包和“每次切页必须重播”不是所有项目的默认需求。

## 7. 跨样本优先级

### P0：先阻止错误交付

1. 全交付面版本与数据期间一致。
2. 口径不混排，计算与倍数文案可复算。
3. 计数、命名与期间同源。
4. 关键来源可定位，结论不超出证据。

### P1：补齐可用性

1. reduced-motion 全链路覆盖。
2. Tabs/抽屉的键盘、焦点和 ARIA 状态同步。
3. 移动图表有效绘图区与文字可读性。
4. 无 JS、打印和异常状态可读。

### P2：提升演示质量

1. 从均质卡片海转为结论标题 + 主证据 + 异常/行动。
2. 从每次重播转为有意义的数据更新与页面层级过渡。
3. 从项目参数拼贴转为可选择、可验收的主题系统。
4. 截图 manifest 绑定当前成品，避免旧图证明新版。
