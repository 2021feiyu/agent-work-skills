# 四维复检清单与数据纪律（deep-research-report 配套）

复检在所有分片合并后执行一次全量，之后任何单模块修改重拼后再跑一遍终验。

## A. 编号连续性

- 章节号全局连续：模块1(1.1-1.5) → 模块2上/中/下(2.1-2.6) → 模块3(3.1-3.7) → 模块4 → 模块5 → 附录
- 同模块多分片：一级标题统一"# 模块N：…（上/中/下）——副题"格式
- 小节样式：常规阶段节用"核心目标/关键环节/角色分工/输入输出/风险优化"模板；专项深化节用编号小节（如 2.6.1、3.7.2）与主流程区分

## B. 跨模块数据一致性（最高频问题来源）

建立核对表逐项过：

| 指标 | 出现位置 | 口径1 | 口径2 | 处置 |
|---|---|---|---|---|

处置规则（按场景）：
1. **同一指标两个区间**（实例：度假酒店GOP率 30%-40% vs 28%-35%）→ 取并集综合区间（28%-40%），两处互引"细分口径见X.Y"
2. **同一数据两个时点**（实例：REITs存量"截至2025年12月" vs "11月14日"）→ 统一到来源最精确的时点，加"与X.Y一致"
3. **同一时点两个数字**（实例：T-12月签约率 ≥60% vs ≥70%）→ 统一为一个
4. **特例数据超一般区间**（实例：Club Med直销占比70%+ vs 行业健康区间40%-60%）→ 不删数据，显式写明差异来源（全球会员体系支撑）
5. **总量分项对不上**（实例：7+17+126+120=270 vs 总数179）→ 改为"版本统计口径差异"，不硬凑

## C. 术语首现顺序

- 术语表要么真按首现排序，要么声明"按报告结构排列"（做不到就别宣称）
- 术语表每个词必须在正文真实出现；新增术语在正文补"业内也称XX"锚点
- 同一术语多译法全文统一（实例：RevPAR 统一"每间可供出租客房收入"）

## D. 交叉引用有效性

- grep 全文"模块X.Y""X.Y节"，逐条验证目标节存在且编号正确
- 双向引用成对（实例：2.6"详见模块3.7" ↔ 3.7"详见模块2.6"）
- 总览模块为专项深化留路标（实例：1.4 增"混合型项目"段指向 2.6/3.7）
- 趋势模块回扣专项深化的关键结论（实例：5.2.2 轻资产化补 Club Med 八成轻资产对标）

## E. 物理与算术 sanity check

- 倒排表每行：时点 vs 任务量级是否物理可行（实例：T-15月"主体结构过半"不可能）
- 数字拆分加总 = 总数
- 增长率与基数自洽（实例：56.15亿人次 × 1.162 ≈ 65.2亿 ✓）
- 授权费/佣金类比例与基数相乘量级合理

## 数据纪律细则

1. WebSearch 核实 2024-2026 数据，每处标注年份与来源类型（官方统计 / 企业披露 / 第三方平台 / 媒体报道 / 行业普遍参考值）
2. 查不到权威口径 → 区间表述 + "行业普遍参考值"，严禁编精确数
3. 严禁虚构政策文件名与文号；引用文件用全称+印发年份
4. 同名总量多来源有出入（如全球度假村 68 vs 69 家）→ 分项表述回避总数
5. 价格类数据一律标"第三方平台参考口径"并注年份
6. 节末"数据来源说明"逐条对应正文数据，便于后续复检回溯

## 终验命令模板

```bash
# 1) 旧文本残留（应=0；grep -c 输出 0）
grep -c "旧口径A\|旧口径B\|旧译法A" 报告.md

# 2) 新文本落位（逐项应≥1）
for p in "新口径A" "新口径B" "新增句关键词"; do printf "%s->%s\n" "$p" "$(grep -c "$p" 报告.md)"; done

# 3) 结构完整性
grep -n "^# \|^## " 报告.md | tail -20
```

注意：校验模式本身也可能写错（实例：模式" CLUB Med"带前导空格导致误报0），先确认模式串正确再下结论。
